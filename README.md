# AirDictate

**Диктовка и управление компьютером с воздушного пульта.** Нажали кнопку микрофона на пульте, сказали фразу, замолчали, и сообщение ушло в приложение Claude. Голосом можно управлять Google Chrome. Клавиатура и мышь не нужны.

![Мастер настройки пульта](docs/images/wizard.png)

## Что умеет

- **Диктовка в Claude с пульта.** Кнопка микрофона запускает запись. Пауза в речи или повторное нажатие отправляют сообщение. Клик мышью ставит запись на паузу, текст остаётся в поле.
- **Круговой набиратель.** Цифры, знаки и пробел с пульта в любом поле ввода. Несколько тем оформления.
- **Кнопка подсветки как правая кнопка мыши.**
- **Мастер настройки.** Запоминает кнопку записи и микрофон пульта. Поддерживает любой пульт с кнопкой микрофона.
- **Голос для Google Chrome.** Команды со словом «хром»: открыть сайт, найти, напечатать текст, вкладки, назад и вперёд, прокрутка.
- **Работа в фоне.** Значок в трее, автозапуск с Windows. Задача в Планировщике поднимает программу, если она выключилась.

## Установка

Нужен Windows 10 или 11. Python и установка не нужны.

1. Скачайте архив `AirDictate-1.0-windows.zip` из [релизов](../../releases).
2. Распакуйте и запустите `AirDictate.exe` из папки `AirDictate`.
3. В мастере нажмите кнопку записи на пульте три раза (или «Пропустить», если у вас G10S Pro), отметьте микрофон пульта и сохраните.

Подробная инструкция: [docs/MANUAL.md](docs/MANUAL.md). Список изменений: [CHANGELOG.md](CHANGELOG.md).

## Управление пультом

| Что нажать | Что произойдёт |
|---|---|
| **Микрофон** | начинается запись |
| **Микрофон** во время записи | запись останавливается, фраза отправляется в Claude |
| **Пауза в речи** (2,2 секунды) | то же, что и кнопка: фраза отправляется |
| **OK** (клик) во время записи | пауза, текст остаётся в поле, ничего не отправляется |
| **Вправо** в поле ввода | открывается круговой набиратель |

## Голос для Chrome

Запуск: `AirDictate.exe --chrome`. Команды начинаются со слова «хром»:

- «хром открой ютуб», «хром найди погода в москве», «хром напиши привет»
- «хром новая вкладка», «хром закрой вкладку», «хром следующая вкладка»
- «хром назад», «хром вперёд», «хром вниз», «хром вверх», «хром обнови», «хром энтер», «хром стоп»

Распознавание работает офлайн, модель речи включена в сборку.

## Сборка из исходников

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт скачает модель речи (если её нет), соберёт `dist\AirDictate\AirDictate.exe` и скопирует туда README. Зависимости: `requirements.txt`.

## Статус

Версия 1.0. Диктовка с пульта G10S Pro проверена на Windows 11 с Claude для рабочего стола. Голос для Chrome работает на компьютере автора. Другие пульты и другие версии Claude проверены не все.

## Лицензия

Не выбрана. Пока код можно смотреть и запускать, но использовать, менять и распространять его без разрешения автора нельзя.

> AirDictate не связан с Anthropic. Claude и Google Chrome — названия сторонних программ.
